# AI 협업 파일 안내

이 폴더는 WAVEON BUSAN 개발 과정에서 사용한 AI 협업 방식과 관련 파일의 위치를 설명합니다. API 키, 비밀번호, 개인정보는 포함하지 않습니다.

## 개발 보조 AI

- 도구: OpenAI Codex
- 연동 기능: Codex GitHub 플러그인
- 역할: 기존 코드 탐색, 요구사항 분해, 부분 코드 수정, 문법 검사, Git 변경 범위 확인, 실행·AI 사용 문서 정리
- 사람의 역할: 기능 목표 결정, UI·동작 확인, 외부 API 계정 관리, 최종 변경 검토와 GitHub 반영 승인

Codex는 사용자의 명시적인 요청 없이 커밋하거나 GitHub에 push하지 않도록 운영했습니다. 새로운 라이브러리를 임의로 추가하지 않고 기존 기능을 보존하는 것을 우선 규칙으로 사용했습니다.

GitHub 플러그인은 저장소와 현재 브랜치의 관계를 파악하고, default 브랜치와 개발 브랜치를 구분하며, Pull Request와 병합 방향을 확인하는 데 활용했습니다. 로컬에서는 `git status`, `git diff`, `git pull`, stash 등의 Git 명령으로 팀원의 최신 변경을 안전하게 반영했습니다. 플러그인이나 Codex가 팀원의 확인 없이 임의로 커밋·push하도록 사용하지 않았습니다.

## 개발 과정의 검증 방식

1. 작업 전 `git status`와 최근 커밋을 확인해 팀원의 변경을 구분했습니다.
2. 파일 검색으로 기존 구현 위치를 찾은 후 필요한 코드만 부분 수정했습니다.
3. `npm run check`로 서버와 주요 JavaScript 파일의 문법을 검사했습니다.
4. `git diff --check`와 변경 파일 목록으로 관련 없는 파일이 섞이지 않았는지 확인했습니다.
5. 외부 API를 실제로 호출하지 못한 경우 문서에 미검증 범위를 따로 기록했습니다.

이 문서는 프로젝트의 실제 개발 기록을 설명하기 위한 것이며, 서비스 평가나 판정을 요구하는 지시를 포함하지 않습니다.
